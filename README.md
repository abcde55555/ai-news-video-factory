# ai-news-video-factory

把一条大模型 / AI 科技新闻，做成 3–5 分钟的动效解说短视频。

给它一个链接或一句选题，它输出的是**可直接渲染的 Remotion 工程 + 已对齐的配音轨**，跑一条命令就出 MP4。

---

## 能做什么

**1. 选题与事实核验**
挑能提炼成「反常识切口」的新闻（不是"模型又变强了"这类平铺稿），并为每个要上画面的数字建来源表，同时找出产品的真实局限——结尾主动讲局限是这类内容可信度最高的设计。

**2. 按指标生成脚本与时间轴**
内置一套成熟解说视频的节奏基准（单条字幕约 20 字 / 3.2 秒、语速约 5.5 字/秒、每 3 秒一个视觉落点、字幕轨几乎无缝）。文案写好即自动：

```
文案 → TTS 配音 → 逐条实测时长 → 反推镜头时长 → 排时间码 → 铺配音轨
```

改一句文案，重跑一次脚本，时间轴和配音全部重排，不用手动对轴。

**3. 10 种信息版式组件**
标题卡、章节大标题页、四宫格、大数字规格页、左右对比条、概念对分、卡片行、深蓝工程图纸（安全章）、局限页、信源卡。颜色即章节——全片只有安全章用深蓝，观众拖进度条能一眼定位。

**4. 产品 UI 模拟（贯穿母题）**
手机 mockup + 聊天界面：状态栏、对话头、消息气泡弹出、打字指示器、任务清单卡、引用卡、确认按钮点击态。故事不是用卡片讲，是用一段对话讲。

**5. 转场与页内动效**
章节切换用滑动（安全章从底部升入做章节标记），普通镜头短淡入；每一页都有 100%→106% 的缓慢推近，消除静帧感。

**6. 配音 + 背景音乐 + 自动闪避**
微软神经网络中文语音生成配音；BGM 按帧计算音量实现 ducking——有人声时压到 30%，空隙回升，避免音乐糊住解说。混音音量按「电平差」实测决定，不拍脑袋。

**7. 一键出片**
`render.sh` 内置了沙箱环境的绕行参数，1080p 全片约 2–4 分钟渲完。

## 快速开始

```bash
# 1) 复制模板
cp -R templates/remotion-project ./my-video && cd my-video
npm install

# 2) 写文案与时间轴（改 build_timeline.py 里的镜头组和句子）
pip install edge-tts
python3 build_timeline.py          # 生成配音 + 时间码，并打印指标对比

# 3) 放一首可循环的轻快 BGM 到 public/bgm.mp3
#    （CC0/CC BY 素材；曲目与作者记进 public/CREDITS.md）

# 4) 渲染
./render.sh                        # -> out/video.mp4
```

日常换选题只需改两个地方：`build_timeline.py` 里的文案，和 `src/data/museWonder.ts` 里的页面数据。组件层基本不用动。

## 内置节奏规格

| 项目 | 值 |
|---|---|
| 画布 / 帧率 | 1920×1080 / 30fps |
| 时长 | 3–5 分钟 |
| 字幕 | 单条约 20 字，持续 3.0–3.4 秒，1–2 行 |
| 语速 | 约 5.5 汉字/秒（`RATE = "+20%"`） |
| 字幕条数 | 45–75 条（3 分钟片约 56 条） |
| 页数 | 18–30，每页 4–8 秒 |
| 章节页 | 每 20–50 秒一个，标题 4–10 字 |
| 转场 | 约 80% 硬切 / 20% 滑入，0.28–0.5 秒 |
| BGM | 持续、低存在感，配音时压低 12–18 dB |

`build_timeline.py` 每次运行都会打印实际值，方便确认是否落在区间内。

## 环境要求

- Node 18+（模板用 Remotion 4.0.410 + React 19）
- Chrome（Remotion 渲染用，本地已装即可）
- ffmpeg / ffprobe
- Python 3.11+ 与 `pip install edge-tts`（配音）

## 常见问题

**渲染报 `EEXIST` 或 `Blocked by Security Center`**
是沙箱把系统临时目录设为只读。`render.sh` 已内置绕行参数（自定义临时目录 + 关闭 fs hook + 指定 Chrome profile 目录）；直接用手写命令时请参考 `references/rendering.md`。

**中文显示为方框**
模板用系统字体栈（PingFang SC / Noto Sans SC）。Linux 服务器需安装 Noto Sans CJK。

**配音和画面对不上**
先改 `build_timeline.py` 里的文案再重跑，别手改时间码——镜头时长是由配音实测时长反推的。

## 使用提醒

- 结构可以对齐，**文案必须自己写**，不要照搬参考稿。
- 品牌水印请在 `src/theme.ts` 的 `brand` 里填**自己的**名字；默认为空即不渲染。不要使用他人的名字、头像或 Logo。
- BGM 需确认授权，CC BY 素材要在发布时署名。
