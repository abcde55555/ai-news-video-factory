# 视觉身份设计（每部片子必须重新做）

## 核心原则

**同一个 skill 产出的片子，视觉上必须互相不像。**

模板只提供"工程骨架"（时间轴、字幕轨、渲染管线、组件实现方式），**不提供视觉身份**。
视觉身份必须从这一个产品/题材重新推导：色板、字体、母题、动效力度、分镜结构。

反面教材（真实发生过）：给 Meta 模型做的片子和给 REA 逆向工具做的片子，
色板一字不差（`#F3F1EC` / `#0866FF` / 深蓝 `#0B1A31`）、10 个场景组件 1:1 搬用、
连"REVERSE 水印"都是把上一部的 "WONDER 水印"换了字。这是失败的。

## Step 1：先读产品，再谈设计

开工前必须回答这四个问题，答案写进 `style-spec.md`：

1. **品牌色是什么？** 从官方 logo / 官网 / 产品截图里取，不要自己发明。
   用 `extract_brand_palette.py <图>` 提取主色，得到主色、深色变体、可用的中性底色。
2. **它是什么调性？** 开发者工具（冷、精确）／消费产品（暖、圆润）／研究发布（克制、学术）／
   基础设施（结构、连线）／硬件（暗场、质感）。
3. **它的界面长什么样？** 深色还是浅色？等宽字体还是人文无衬线？圆角还是直角？
   这些直接决定画面底色与字体，不要用默认值。
4. **它自己有什么视觉隐喻？** 逆向 → 字节流/反汇编/内存地址；Agent → 对话流/时间线/任务队列；
   图表渲染 → 画布/坐标系；模型训练 → 集群/曲线。**母题必须来自产品本身。**

## Step 2：题材 → 视觉处方

| 题材 | 底色 | 字体 | 母题 | 动效力度 |
|---|---|---|---|---|
| 开发者工具 / CLI / 逆向 / 安全工具 | 深色 `#0D1117`~`#111827` | 等宽为主（代码、地址、字节） | 十六进制流、反汇编列表、光标闪烁、scanline | 快、精确、少缓动 |
| 消费级 AI 助手 / Agent | 浅暖 `#F6F2E9` + 品牌色 | 人文无衬线 | 对话气泡、手绘角色、柔和阴影 | 柔、有弹性、呼吸感 |
| 研究 / 模型发布 | 白 `#FFFFFF`~`#FAFAF8` | 学术无衬线 + 等宽数字 | 原生图表、脚注、公式 | 克制，几乎只有淡入 |
| 开源框架 / 基础设施 | 冷灰 `#F3F5F7` 或深蓝灰 | 简洁无衬线 | 架构节点、连线、调用链 | 逐段绘制、路径生长 |
| 硬件 / 设备 | 暗场 `#0A0A0B` + 打光 | 大字号无衬线 | 产品照、金属高光、景深 | 缓慢推近、光划过 |
| 安全 / 合规 | 图纸色 **或** 红蓝对抗（二选一） | 说明性无衬线 | 图纸网格 / 攻防箭头 | 检视式、逐条点亮 |

**禁止**：所有题材都用「四宫格 + 三个大数字 + 对比条 + 三条局限」这套分镜。
分镜结构要跟着内容走：逆向工具适合"源码 vs 反编译对照"；Agent 适合"时间线 + 对话流"；
基础设施适合"调用链动画"。

## Step 3：品牌角色动画（灵动的关键）

参考片那种"小人"的灵动感，做法不是画得精细，而是**动作分节 + 错峰弹跳**：

- 用 SVG path 拆成独立部件（头、身体、两条手臂、两条腿），每部件单独 `spring`
- 各部件延迟错开 2-4 帧，形成"先头后手"的跟随感
- 描边动画（`strokeDasharray` + `strokeDashoffset`）让线条"画出来"，而不是整块淡入
- 表情/眼睛用 2-3 帧的状态切换（点 → 弯 → 圆），比连续变形更有卡通感
- 角色要**和 UI 元素互动**：指向卡片、搬走一个方块、把标签贴上——这才是"联动"

## Step 4：色板可以程序化验证的两个硬指标

1. **色板指纹**：主色 Hue 差 < 15° 且底色 ΔE < 5 → 说明和上一部片撞了，必须重设
2. **版式指纹**：与上一部片的场景类型分布重合 > 70% → 说明分镜在套模板

两者任一触发，就不许开渲。

## style-spec.md 模板

```markdown
# 视觉身份 · <片名>

## 产品与调性
- 产品：<名>（<类型：开发者工具/消费产品/研究/…>）
- 官方品牌色：<hex>（来源：<logo 或官网 URL>）
- 调性关键词：<3 个>

## 视觉系统
- 底色：<hex>　主色：<hex>　辅助：<hex>　警示：<hex>
- 字体：标题 <字体>、正文 <字体>、数字/代码 <字体>
- 圆角：<px>　阴影：<描述>
- 母题：<这个产品自己的隐喻，一句话>

## 动效语言
- 入场：<时长/缓动>
- 强调：<方式：高亮刷 / 描边 / 数字跳 / 局部推近>
- 角色/图标动画：<有/无，怎么做>
- 转场：硬切 <n> 次、特殊转场 <哪种>、滑动 <仅章节>

## 分镜结构（与上一部片的差异）
| 章节 | 版式 | 为什么这个版式适合这段内容 |
|---|---|---|

## 差异化自检
- 与上一部片的色板差异：<ΔE/Hue>
- 场景类型重合度：<xx%>
```

## 开发者工具类题材的动效处方（实测可用）

代码见 `references/examples/devtools-motion-lab.tsx`（可直接拷进工程当范式）。

### 三个"抓眼"动效，共同点：**动效即论证**——不是装饰，而是在演示产品做的事

| 动效 | 怎么做 | 为什么抓眼 |
|---|---|---|
| **字节扫描锁定**（Scan） | 满屏十六进制按列独立滚动；一条渐变扫描线自上而下；距扫描线越近的字节越亮；扫到目标处弹出锁定框（`BYTE @ 0x100004A70` → `0x4A 0x7D 0xBE` → `→ string literal`） | 把"从字节里读出东西"这个抽象过程变成可见动作 |
| **反编译重建**（Reconstruct） | 汇编行先轻微滚动→**定格**→横向 glitch 抖动 8 帧→整体上滑清空→C 代码逐行浮入→角落出现「✓ 重建完成 · 字节级一致」 | **"乱码变人话"是全片最强的一击**，也是产品核心价值 |
| **逐字节对齐**（Verify） | 左右两栏**同一组字节**（必须相同，否则观众觉得"对不上"）；逐列点亮：匹配绿、差异琥珀；底部进度条 + 计数器 `90 / 140 bytes verified` | 唯一能证明"不是 AI 瞎猜"的画面 |

### 实现要点（踩过的坑）

- `random()` 只接受 **number** 种子，字符串要自己 hash（否则 TS 报错）
- 交叉淡入淡出的两层**会叠字**：旧层必须整体快速退场（8 帧内 opacity→0 + 上滑），新层延迟 10 帧再开始
- 对比类动效两侧必须用同源数据，否则"对齐"的说服力为零
- 面板 `minHeight` 要贴合行数，否则大片空白显得没做完
- 动效节奏对齐字幕：一条字幕 3-4 秒 = 一次动效循环

### 其他备选（本片未采用）

- 十六进制流冲刷转场（hex wipe）：适合章节切换，但连续用会晕
- 调用链光点追踪（call graph trace）：适合"它怎么找到这个函数"的段落
- 终端逐字打字 + 块状光标：适合命令行演示段
- glitch/像素错位：只做转场瞬间，不能当常态（廉价感）
