# 范例：REA（逆向工程工具）的视觉身份

> 这份 spec 用来示范「同一个 skill 对不同题材必须给出不同设计」。
> 反例警告：REA 最初被做成了和 Meta 模型片一模一样的样子——米白底、蓝主色、
> 四宫格、手机 mockup、深蓝安全章、REVERSE 平铺水印（那是把上一部的 WONDER 水印换了字）。
> 下面是根据 REA 这个产品本身推导出的正确设计。

## 产品与调性

- 产品：REA —— macOS / Windows 应用逆向分析工具（把二进制、Electron、APK 拆开看它怎么跟服务器对话）
- 类型：开发者工具（**深色终端产品**，不是消费级应用）
- 官方品牌色：从 REA logo / 官网取（`extract_brand_palette.py rea-logo.png`）
- 调性关键词：**冷、精确、拆解、可验证**

## 视觉系统

| 项 | 值 | 理由 |
|---|---|---|
| 底色 | `#0D1117`（全片深色） | 产品本身就是终端/编辑器形态，用米白底等于换了品类 |
| 面板 | `#161B22` | 二级信息容器 |
| 主色 | 终端绿 `#3FB950` 或琥珀 `#D29922` | 二进制/汇编的视觉联想；不要用蓝色（那是上一部片子的） |
| 字体 | 标题 PingFang，**数据与地址用等宽** | 十六进制、内存地址、代码必须等宽，这是可信度的来源 |
| 圆角 | 6-8px | 工具感，不要 22px 的柔和圆角 |
| 母题 | **源码 ↔ 反编译对照**、字节流、内存地址、Mach-O/APK 结构树 | 全部来自逆向工程本身 |

## 动效语言

- 入场：快（12-16 帧），`damping` 高，几乎没有回弹——工具就要准
- 强调：**逐行描出**（打字机/scanline）、地址高亮闪一下、字节被"选中"
- 角色动画：不要做人形角色；替代方案是 **光标**（块状 cursor 闪烁、跳动）与**扫描线**
- 转场：以硬切为主；章节切换用「终端清屏」（整屏向下滚动一行）或「16 进制块噪点」

## 分镜结构（与上一部片的差异）

| 章节 | 版式 | 为什么适合这段内容 |
|---|---|---|
| 开场 | 左：一段二进制字节；右：反编译后的伪代码，逐行刷出 | 一眼说明"它把看不懂的东西翻译成人话" |
| 是什么 | 单行标题 + 终端命令（`$ rea inspect app.app`）+ 真实输出 | 工具类必须让观众看到命令行 |
| 支持目标 | 文件类型卡片：Mach-O / Electron / APK / 图片，逐项"扫描"点亮 | 原文就是四类目标，用扫描感而不是四宫格 |
| 工具数量 | 超大等宽数字 38 / 40+ + 进度条 + 分类小标签 | 数字是核心卖点，等宽字更可信 |
| 工作原理 | 三节点流程图：二进制 → 解析器 → 可读结构（箭头逐段绘制） | 逆向就是一条流水线 |
| 安全边界 | **琥珀色警示条**（不是深蓝图纸）：允许 / 不允许 两栏对照 | 深蓝图纸是上一部片子的安全章语言，必须换 |
| 局限 | 终端式 `WARN` 输出，逐条打印 | 与工具的调性一致 |

## 差异化自检

- 与上一部片（Meta 模型）的色板差异：底色 `#0D1117` vs `#F3F1EC`，ΔE 远超阈值；主色绿/琥珀 vs 蓝，Hue 差 > 90°
- 场景类型重合度：仅保留"信源页"，其余全部重做 → 重合度 < 20%
- 母题检查：无手机 mockup（REA 不是手机应用）、无平铺水印、无深蓝安全章

## 结论

同一套工程骨架（时间轴 / 字幕 / 渲染管线），换掉的是：**底色、主色、字体、母题、版式组合、动效锐度**。
观众看到的应该是"一个拆二进制的工具"，而不是"又一个科技解说模板"。
